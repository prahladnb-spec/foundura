# Foundura: notes for working in this repo

- Monorepo: pnpm + Turborepo. Build `@foundura/shared` before the apps (`pnpm --filter @foundura/shared build`).
- API: NestJS 11 + Drizzle (not Prisma). Schema in `apps/api/src/db/schema.ts`; after changing it run `pnpm --filter @foundura/api db:generate` and commit the new SQL in `apps/api/drizzle/`.
- Use explicit `@Inject(...)` in Nest constructors; tests run through Vitest with SWC.
- Validate request bodies with the shared zod schemas via `parseBody`.
- Scheme rules are JSON `Condition` trees from `@foundura/shared`. Never add a fact the scan doesn't collect; `test/schemes-seed.test.ts` enforces this. New schemes ship with `last_verified_at = null` until an editor checks the official source. Scheme Hindi lives in `schemes.translations.hi` with a fingerprint of the English; never serve a translation whose fingerprint doesn't match (use `localizeScheme`).
- Privacy rules: don't store anonymous scan answers, don't expose turnover/funding/shareholding publicly, record consent changes as new ledger rows, and keep `/me/export` and `DELETE /me` complete when adding tables with personal data.
- The platform never handles money.
- Founder document templates live in `apps/web/src/documents/` as structured blocks; the Word/Excel/PowerPoint files are generated from them, so never commit binary templates. Legal instruments set `lawyer: true`; finance documents are matched by `checkWith()` for a CA notice. Never claim a professional review in copy: `REVIEWS` in `documents/index.ts` is the only place, and only after a real review. When you change a legal point, update `CHECKED_ON` and keep the guide and template consistent. Guides and templates are English; titles and summaries also need Hindi. Spreadsheets that are plain tables use the `grid` builder; Hindi or example versions go in `variants.ts`. Glossary terms live in `apps/web/src/glossary.ts` with both languages.
- Events: public endpoints only return `published` events; imported events come from `event_sources` through `EventSyncService` (iCalendar or schema.org JSON-LD) and must be fetched with `safeFetchText`, which blocks private networks. `EVENT_SYNC_ALLOW_PRIVATE` is for tests only.
- Web copy: sentence case, plain words, no all-caps labels. Interface text goes in `apps/web/src/i18n/en.ts` and `hi.ts` (same shape); email text in `apps/api/src/mail/templates.ts`. Design tokens live in `apps/web/src/app/globals.css`.
- Tests: `pnpm test` (needs Postgres; e2e uses `TEST_DATABASE_URL`, default `foundura_test`). Browser tests: `pnpm build && pnpm e2e` (Playwright, in `e2e/`, fresh `foundura_e2e` database). When you change a page or flow, update its spec; new interface text on Hindi pages must pass the untranslated-English check in `e2e/tests/hindi.spec.ts`.
